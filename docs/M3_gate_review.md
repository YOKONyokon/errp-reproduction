## 4. 残余差异根因（5 类，可解释、非随机误差）

1. **CV 折数与被试划分**：论文 MATLAB 与本复现的折数/被试内划分口径不同，
   对多被试数据集影响最明显。
2. **基线校正**：基线窗口与实现细节差异影响直流偏置。
3. **GNB 实现**：高斯朴素贝叶斯的方差/先验实现口径不同，是 GNB 偏差最大的主因。
4. **空间滤波**：xDAWN/FCB 通用库包装与官方源码口径不同（已按官方实现修正，
   见 xDAWN 官方广义特征值单类成分 + 逐试次 z-score、FCB 归一化）。
5. **MATLAB vs Python 工具链**：MVPA-Light 与 scikit-learn 的求解器/数值精度差异。

> 偏差呈系统性、可归因，且有符号偏差仅 +2.53（无大面积方向错误），
> 支持"实现口径差异"而非"方法错误"的判断。
